# Akarsh Bajpai contact site

A small static contact page published through GitHub Pages. The repository contains `index.html` and a `CNAME` file for the custom domain.

## Preview and update

Open `index.html` locally in a browser. To publish an update, commit the edited HTML to the branch configured in the repository's GitHub Pages settings and verify the live page after deployment.

The page currently functions as a contact landing page, not a full project portfolio. Project source and technical details are available from the [GitHub profile](https://github.com/not-a-hack-er).

Before sharing the site with recruiters, verify that the email address, Play Store link, and custom domain shown in `index.html` are current.
